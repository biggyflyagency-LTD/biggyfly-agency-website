# Biggy Fly Agency Website

A comprehensive 6-page website for Biggy Fly Agency - a premier immigration and travel services company based in Kenya.

## Project Overview

**Organization:** biggyflyagency-LTD  
**Repository:** biggyfly-agency-website  
**Language:** HTML, CSS, JavaScript

## Features

### 6-Page Structure

1. **Home (index.html)** - Landing page with featured services and call-to-action
2. **Services (services.html)** - Detailed service listings and process
3. **About Us (about.html)** - Company mission, vision, and values
4. **Offices (offices.html)** - Location information and maps for both offices
5. **Contact Us (contact.html)** - Contact form, FAQ, and contact information
6. **Authentication (auth.html)** - Login, Sign Up, and Secure Document Upload
